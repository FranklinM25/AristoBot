# AristoBot

A modular, multi-purpose Discord bot built to assist with server utilities and voice channel audio playback.

## Project Status

**Current Version:** `v0.1.0-alpha`

The project is currently in its foundational stage. The core architecture is established, featuring a stable connection to the Discord API and basic slash commands to verify functionality. The first major feature under development is an audio playback system for voice channels.

## Repository Structure

This repository is organized as a monorepo to separate the bot's core logic from future client interfaces:

- `/bot` - Core Discord bot application built with TypeScript and Node.js.

## Tech Stack

- **Runtime:** Node.js
- **Language:** TypeScript
- **Discord API:** discord.js
- **Code Quality:** ESLint
